# **Project Overview**

The Cycle Pricing Engine is a Spring Boot-based REST API application designed to manage bicycle components and calculate the total price of a cycle based on the current prices of its individual components.

The application provides APIs to manage cycle parts, update component prices, calculate the total cycle price, and maintain a history of price changes. It uses Spring Boot, Spring Data JPA, and MySQL for backend development and data persistence.

This project demonstrates practical knowledge of REST API development, database integration, CRUD operations, input validation, exception handling, and Spring Security configuration.





# **Features**

Component Management: Add, view, update, and delete cycle components.

Dynamic Price Management: Update the prices of individual components.

Cycle Price Calculation: Calculate the total price of a cycle based on the selected components and their current prices.

Price History: Maintain a record of component price changes.

RESTful APIs: Expose endpoints to interact with the application.

Database Integration: Store component information and price history in MySQL.

Exception Handling: Handle application errors using a global exception handler.

Input Validation: Validate incoming request data.

Security Configuration: Configure API access and HTTP security settings.
